# Finance

## Stock Screener (NEW!)

Comprehensive stock screening tool for tech stocks with advanced metrics:
- Revenue growth and acceleration analysis
- Gross margin tracking
- Magic number (sales efficiency)
- Comp-adjusted acceleration

**Quick Start:**
```bash
python3 sample_data_demo.py
```

See [STOCK_SCREENER_README.md](STOCK_SCREENER_README.md) for full documentation.
